會花錢嗎？
Google 要求綁信用卡，但每月有免費額度。換地點、距離或種類後第一次抽，會查詢 2 到 3 次，附近店家太少時會再補查 1 次；之後按「再抽一次」不會再查詢。每月免費的查詢次數，一般日常吃飯用不完。第 7 步會教你設上限，避免意外。

  1. 登入 Google Cloud

    打開 Google Cloud 主控台，用你的 Google 帳號登入。第一次使用會請你同意服務條款。

  2. 建立專案

    點畫面左上角的專案選單，選 新增專案，名稱可以填「吃哪間」，按建立。完成後確認左上角已切換到這個專案。

  3. 綁定帳單

    打開左側選單的 帳單，依畫面指示建立帳單帳戶並輸入信用卡，再把它連結到剛剛的專案。

  4. 啟用兩個服務

    到 API 和服務 → 程式庫，分別搜尋下面兩個並按「啟用」：

    Maps JavaScript API
    Places API (New)

    注意第二個要選名稱有 (New) 的那個。

  5. 建立金鑰

    到 API 和服務 → 憑證 → 建立憑證 → API 金鑰，畫面會跳出一串 AIza 開頭的金鑰，先複製起來。

  6. 把金鑰鎖在這個網站（很重要）

    在憑證頁點進剛建立的金鑰：

    「應用程式限制」選 網站，新增下面這個網址：

    這個網頁還沒放上網路，請先完成架設，再回來複製正式網址。

    「API 限制」選 限制金鑰，勾選第 4 步的兩個服務，然後儲存。這樣就算金鑰被別人看到，在其他網站也用不了。

  7. 設定用量上限

    到 API 和服務 → 已啟用的 API 和服務 → Places API (New) → 配額與系統限制，把查詢次數上限調低。如果有「每日」上限，建議設為 30。

    也可以到 帳單 → 預算與快訊 設一個小額預算，超過時 Google 會寄信通知你。

  8. 貼回這個網頁

    回到首頁貼上金鑰並儲存。剛設定好的金鑰有時要等幾分鐘才會生效，第一次抽不到可以稍等再試。
